# AutoTeams v13.0a — My Profile Dashboard

## New route

- `/profile`

## Features

- Permanent My Profile navigation item
- Signed-in account summary
- Context-profile cards for:
  - Business
  - Friendship
  - Community
  - Sports
  - Education
- Create missing contextual profiles
- Profile-completion percentage
- Team DNA freshness and confidence
- Edit, Atlas and Team DNA quick actions
- Current workspace-membership summary
- Links to Privacy, Security and Settings
- My Team DNA navigation label

## Behaviour

Editing a contextual profile does not restart the Atlas interview.

Users choose when to refresh Team DNA from Atlas or the Team DNA page.
