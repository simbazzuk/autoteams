# AutoTeams v9.1 — Guided Team Builder

This release redesigns the workspace-scoped Team Builder.

## Improvements

- Wider and more balanced two-column layout
- Four clearly numbered input stages
- Full-width workspace and form controls
- Talent pool and department filters
- Live eligibility summary
- Optional employee restriction cards
- Clear privacy boundary messaging
- Useful recommendation preview before generation
- Improved recommendation cards and explanation
- Responsive single-column layout
- Existing workspace, people and talent-pool model retained

## Test

1. Open `/workspaces` and select `Example Company`.
2. Open `/people` and confirm employees are available.
3. Open `/talent-pools` and review the sample pools.
4. Open `/team-builder`.
5. Select a workspace, pool or department.
6. Choose a team size and purpose.
7. Optionally restrict the candidates.
8. Select `Ask Atlas to Build Team`.

The prototype continues to use local storage for workspace data.
Firebase, Firestore and Gemini configuration are unchanged.
