# AutoTeams v13.0d — Notifications & Workspace Membership

## New routes

- `/notifications`
- `/profile/membership`

## Notifications

- Unread count
- All and unread filters
- Mark one or all as read
- Dismiss notifications
- Atlas reminders
- Workspace updates
- Team recommendations
- Security alerts
- Notification preferences
- Weekly digest preference

## Workspace Membership

- Workspace selector
- Member counts
- Owners
- Administrators
- Team Leaders
- Team Members
- Role changes
- Member removal
- Pending invitations
- Invitation revocation

## Readability improvements

The Team DNA Dashboard and new pages now use a larger typography scale:

- Larger trait headings
- Larger descriptions
- Larger percentages
- Larger Atlas Health labels
- Larger card and button text
- Improved spacing

## Important

Notifications, sessions and membership changes are still local prototype data.
Production email delivery, audit logging and server-side role enforcement belong
in the future Cloud Edition.
