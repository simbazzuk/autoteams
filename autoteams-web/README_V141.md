# AutoTeams v14.1 — UX Foundation

## New routes

- `/home`
- `/product-guide`

## Home

The old dashboard now redirects to Home.

Home provides:

- Personal greeting
- Product progress
- One recommended next step
- Workspace health
- Atlas profile health
- Guided end-to-end journey
- Direct links to the relevant feature

## Product Guide

The Product Guide explains:

- The seven-step journey
- Workspace
- Talent
- Talent Pool
- Contextual Profile
- Team DNA
- Atlas
- User roles and responsibilities

## Navigation

Navigation has been simplified around:

- Home
- Me
- Workspace
- Atlas
- Administration

## Readability

This release introduces a larger baseline typography and more consistent:

- Hero headings
- Section headings
- Card titles
- Body text
- Buttons
- Spacing
- Next-step guidance
