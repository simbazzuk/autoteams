# AutoTeams v13.5 — Demo Environment

## New route

- `/demo`

## Datasets

- Business — Acme Technology
- Friendship — City Social Circle
- Community — Community Action Network
- Sports — Northside Sports Club
- Empty/reset state

## Populated local data

Each demo includes realistic:

- Workspace
- Talent Directory
- Talent Pools
- Workspace memberships
- Owners, Administrators, Team Leaders and Team Members
- Pending invitations
- Contextual profiles
- Completed, incomplete and stale Atlas interviews
- Team DNA states
- Notifications
- Existing teams
- Atlas recommendation data

## Usage

1. Open `/demo`.
2. Select a dataset.
3. Choose `Load Selected Dataset`.
4. Refresh or navigate to the relevant pages.
5. Use `Reset Demo Data` to return to an empty local state.

No Firebase data is written.
