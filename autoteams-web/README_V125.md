# AutoTeams v12.5 — Contextual Profiles & Atlas Question Packs

## Contextual profiles

Users can maintain separate Team DNA profiles for:

- Business
- Friendship
- Community
- Sports
- Education

Each profile has:

- Context-specific fields
- Independent consent settings
- Independent Atlas answers
- Independent suggested roles
- A strict context boundary

## Profile fields

### Business
Job title, department, experience and time zone.

### Friendship
Optional age range, optional gender, preferred group size and planning style.

### Community
Cause, relevant experience and optional private accessibility requirements.

### Sports
Sport, participation role, experience, position, competitive preference and
leadership interest.

### Education
Education level, subject, project experience and presentation confidence.

## Atlas

Atlas now combines:

1. Core collaboration questions
2. Context-specific question packs

The question packs cover Business, Friendship, Community, Sports and Education.

## New or updated routes

- `/onboarding/profile`
- `/atlas`
- `/team-dna`

## Test

1. Open `/onboarding/profile`.
2. Create one profile for each context.
3. Confirm each context shows different fields.
4. Save each profile.
5. Open `/atlas`.
6. Switch between profiles.
7. Confirm the questions change by context.
8. Complete a question pack.
9. Open `/team-dna`.
10. Confirm each contextual Team DNA is shown separately.

Data remains in local browser storage for this test release.
