# AutoTeams v11.0 — Product Experience Release

## Main changes
- People renamed to Talent.
- `/people` redirects to `/talent`.
- New 8-step Get Started journey.
- New Teams page.
- Dashboard workspace progress and next action.
- Team Builder renamed Build Teams with Atlas.
- Insights presented as Atlas Insights.
- Navigation updated to Workspaces, Members, Talent, Talent Pools and Teams.
